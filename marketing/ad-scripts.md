# Boxy — 광고 영상 시나리오 v1

**작성일**: 2026-04-29
**용도**: Week 1 Day 5-7 영상 제작용. Week 2 Day 8 페이스북 광고 ₩100,000 캠페인 (각 ₩50,000 × 2종).
**길이**: 각 15초 세로 (9:16 또는 9:19.5)
**해상도**: 1080×1920 minimum (인스타/페북 권장)

---

## 영상 1 — 실패형 (메인 후킹, boxy-plan §B-1-1 좌절 후킹 채택)

### 컨셉
"95% 채웠는데 마지막 한 칸 안 들어감" — boxy-plan §B-1-1 정확히 매핑. AppLovin 데이터 기준 fail tone이 top 26%.

### 핵심 메시지
- 시청자가 "내가 풀어보고 싶다" 느낌 → 다운로드 동기

### 스토리보드 (15초, 60fps 또는 30fps)

| 시간 | 화면 | 사운드 | 텍스트 오버레이 | 비고 |
|---|---|---|---|---|
| 0.0-0.5s | 빈 학교 가방 + 회색 6×8 그리드 표시. 트레이에 5개 아이템 (책, 물병, 노트, 도시락, 사과). | (배경 BGM 드럼 비트 시작) | "Pack everything..." | 타이포그래피: Plus Jakarta Sans Bold 흰색 |
| 0.5-3.0s | 빠른 컷 — 책 → 가방 (탁), 물병 회전 → 가방 (탁), 노트 → 가방 (탁), 도시락 → 가방 (탁) | "탁 탁 탁 탁" 만족스러운 사운드 + BGM 점점 빨라짐 | 자막 없음 (몰입) | 컷 간격 ~0.6s |
| 3.0-5.0s | 가방 95% 채워짐. 한 칸만 비어있음 (좌상단 또는 강조 위치). 마지막 아이템 = L자 모양. | BGM 잠시 멈춤. 시계 째깍 | "...just one more." | 텍스트 페이드인 |
| 5.0-9.0s | 카드 드래그 → 회전 시도 → 안 들어감. 회전 또 시도 → 또 안 들어감. (3번 시도, "삑" 거절 사운드 강조) | "삑 삑 삑" + 좌절감 BGM (낮은 키 minor) | "Why won't it fit?!" 8s쯤 | 좌절 강조 — 시청자 감정 이입 |
| 9.0-11.0s | Boxy 마스코트 슬픔 표정 (눈물 한 방울) 등장 → 화면 가운데 | "흑..." 효과음 | "Help Boxy 🥲" | Boxy = 노란 큐브 + 슬픔 표정 |
| 11.0-13.0s | 화면 분할 → "결국 나는 풀었다" 빠른 컷: 회전 한 번 더 → 들어감 → 가방 가득 → 별 3개 컨페티 | 팡파레 + 컨페티 효과 | "Can YOU pack it?" 큰 텍스트 | 도전 의식 자극 |
| 13.0-15.0s | "Boxy" 로고 + 노란 #FFD60A 배경 + "Pack & Fit Puzzle" + 다운로드 CTA | BGM 마무리 화음 | 로고 / "Free on Google Play" | 아이콘 + 별점 (출시 후 가짜 별 X) |

### 음향 큐 시트
- 0:00 — BGM start (drums, ~120 BPM)
- 0:30 / 1:30 / 2:30 / ... — "탁" 셀 채움
- 3:00 — BGM 정지, 시계 효과음
- 5:00, 7:00, 9:00 — "삑" 거절 효과음
- 9:00 — Boxy 슬픔 효과음 ("흑")
- 11:00 — 회전 + 팡파레 (chord up)
- 13:00 — 로고 reveal + final chord

### 컷 가이드 (편집자용)
- 총 컷 수: ~12개
- 평균 컷 길이: 1.25s
- 핵심 hold: 95% 모먼트 (3s) + Boxy 슬픔 (2s)
- 마지막 2s: 로고 + CTA 풀화면

### 제작 방법
1. Unity Editor에서 Gameplay 씬 실행 → 위 시퀀스 직접 플레이
2. macOS 화면 녹화 (Cmd+Shift+5) 또는 Unity Recorder 패키지 사용
3. iMovie / DaVinci Resolve로 컷 편집 + 텍스트 오버레이 + BGM
4. 사운드 효과: freesound.org / Mixkit (CC0)
5. BGM: Pixabay Music / YouTube Audio Library

## 영상 2 — 성공형 (만족 후킹, A/B 테스트 보조)

### 컨셉
빠른 클리어 + 별 3개 + 컨페티. ASMR 만족감. boxy-plan 광고 영상 4종 중 2번 "성공형".

### 핵심 메시지
- "이 게임 만족감 좋다" 느낌 → 다운로드 동기

### 스토리보드 (15초)

| 시간 | 화면 | 사운드 | 텍스트 오버레이 | 비고 |
|---|---|---|---|---|
| 0.0-1.0s | 빈 트렁크 + 8×6 그리드. 트레이에 6개 아이템 (옷, 가방, 카메라, 여권, 책, Boxy 키링). | (피아노 잔잔한 BGM) | "Pack like a pro" | 여행 트렁크 테마 |
| 1.0-7.0s | 매우 빠른 컷 — 6개 아이템 모두 0.8s 간격 회전 + 배치. 각 컷 끝에 "찰칵" 만족 사운드 | "찰칵 찰칵 찰칵..." × 6 + BGM crescendo | 자막 없음 | 무리 없이 술술 풀리는 느낌 |
| 7.0-9.0s | 마지막 1×2 아이템 회전 → 가방 마지막 칸 채움 (slow-mo 0.5s 강조) | "팡파레" 시작 | "Perfect fit!" | slow-mo로 만족감 극대화 |
| 9.0-11.0s | 가방 가득 + Boxy 환호 마스코트 점프 등장 | 환호 효과음 ("우와아") | "★★★" 큰 별 3개 컨페티 | 풀화면 컨페티 |
| 11.0-13.0s | 화면 빠르게 페이드 → 다음 레벨 자동 시작 (가방 → 박스 → 트렁크 빠른 전환 보여줌) | BGM 화음 변화 | "50 levels" | 콘텐츠량 어필 |
| 13.0-15.0s | "Boxy" 로고 + 노란 배경 + CTA | 마무리 chord | "Free on Google Play" | 동일 |

### 음향 큐 시트
- 0:00 — 잔잔한 피아노 BGM
- 1:00 ~ 7:00 — "찰칵" × 6 + crescendo
- 7:00 — 팡파레 시작 (slow-mo)
- 9:00 — 환호 효과음 + 컨페티 사운드
- 11:00 — 페이드 + chord shift
- 13:00 — 로고 reveal

### 컷 가이드
- 평균 컷 길이: 0.8s (속도감)
- Slow-mo: 7-9s (2초)
- 컨페티 풀화면: 9-11s

## A/B 테스트 발사 계획 (Week 2 Day 8)

| 영상 | 예산 | 목표 CTR | 목표 CPI |
|---|---|---|---|
| 1 (실패형) | ₩50,000 | ≥ 1.5% | ≤ ₩1,500 |
| 2 (성공형) | ₩50,000 | ≥ 1.5% | ≤ ₩1,500 |

### 노출 5,000+/영상 확보 → 통계 신뢰
- CPM ₩10,000 가정 → 5,000 노출/₩50,000

### Day 11 의사결정
- 1번 CTR ≥ 1.5% → 메인 메시지 좌절 후킹 확정 → 본격 UA
- 2번이 더 높음 → 메시지 변경 (성공 만족감 강조) → ASO 카피 변경
- 둘 다 < 1.0% → 영상 컨셉 재검토 (메커닉 자체 재고 X — 시장 갭에 더 맞는 영상 찾기)
