출시 전 작업 (정수):

  1. 이 페이지 브라우저에서 열기 → 큰 아이콘 영역 우클릭 → "이미지 저장" or 스크린샷 → icon-master-1024.png
  2. 또는 디자인 도구 (Figma/Pixelmator)에 SVG import → 1024×1024 PNG export
  3. iOS: Xcode에서 모든 사이즈 자동 생성
  4. Android: Assets/Plugins/Android/res/mipmap-anydpi-v26/ic_launcher.xml 에 adaptive icon 정의
  5. Adaptive Icon foreground SVG는 안전 영역(중앙 66%) 안에만 마스코트 배치

대안: Scenario MCP로 더 디테일한 일러스트 + 음영/하이라이트 추가 가능. 이 SVG는 v1.0 minimum viable icon.
