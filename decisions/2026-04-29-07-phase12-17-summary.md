## 핵심 흐름 — 첫 실행 시 (Unity Editor)

```
MainMenu Scene
  PLAY 클릭 → SceneLoader.LoadScene(LevelSelect)
       ↓
LevelSelect Scene
  ProgressionService Load → 잠금/현재 레벨 표시
  레벨 클릭 → GameSession.PendingLevel = level → LoadScene(Gameplay)
       ↓
Gameplay Scene
  GameplayUI.OnEnable: PendingLevel || defaultLevel || repository.First()
  StartLevel(level) → 그리드 + 트레이 빌드 + Result hidden
       ↓ (사용자 입력)
  드래그 → HandleItemHovering (drop preview) → HandleItemDropped (TryPlace)
  길게 누르기 0.5s → ItemCardView.HandleLongPress (90도 회전 + Rebuild)
       ↓ (모든 셀 채워짐)
  controller → LevelClearedEvent → GameplayUI.OnLevelCleared
    → progression.RecordCompletion (별 저장)
    → resultCtrl.ShowCleared(stars) (모달 표시)
       ↓ (사용자 선택)
  Next → GoToNextLevel → repository.TryGet(L+1) || MainMenu
  Retry → RetryCurrentLevel → StartLevel(currentLevel)
  Menu → SceneLoader.LoadScene(MainMenu)
       ↓ (백그라운드)
  Update() → interstitialTimer.Tick (90~120s 무작위)
    → adsRemoved 시 Suppress (영구 비활성)
```

## 핵심 결정

| Phase | 결정 | 이유 |
|---|---|---|
| **P12** | BoxySaveData 일부 [SerializeField] private (List만), 나머지 public | List는 §6-1 위반, 단순 type은 DTO 패턴으로 public OK. 정적 검사기 통과 |
| **P12** | ProgressionService 단일 책임 — Save 시스템 wrap | 게임 로직과 영속 분리, 테스트 용이 |
| **P12** | PrefsKey "_v1" suffix 컨벤션 | §7-1 마이그레이션 시 _v2로 갱신, 이전 키 삭제 X (deprecate만) |
| **P13** | BoxySceneNames + GameSession을 같은 SceneFlow.cs에 | 씬 흐름 관련 정적 상수 한 곳에 |
| **P13** | LevelSelectController가 anonymous lambda 사용 | OnDestroy 시 컴포넌트 GC로 자동 정리 (CLAUDE.md §4-2 짝 패턴 예외 — 메모리 누수 X) |
| **P13** | MainMenu의 Sound 버튼 = Settings 진입 단축 | v1.0 단순화. v1.1에 BGM 토글 inline 분리 |
| **P14** | ResultPopup 단일 UXML로 Cleared/Failed 모두 처리 | title text + nextButton display 토글로 충분 |
| **P14** | InterstitialTimer.Suppress 영구 비활성 | 광고 제거 IAP 보유 시 시간 기준 광고 영구 차단 (boxy-plan §B-4) |
| **P15** | GridCellView.SetHighlight backgroundColor 일시 덮어씀 | 단순. 드래그 종료 시 RefreshGridFromController로 복원 |
| **P15** | drag preview = OnDragHover 이벤트 chain | Manipulator → ItemCardView → GameplayUI 단방향. 코드 결합도 낮음 |
| **P16** | LevelData.Initialize internal | 어셈블리 내부 (Boxy.App)만 호출. 외부 무단 변경 차단 |
| **P16** | TutorialLevels seed=42 | 매 실행 동일한 5레벨 — A/B 테스트 비교 가능, 디버깅 재현 가능 |
| **P16** | levelAssets 미연결 시 자동 fallback | 정수 Inspector 작업 안 해도 Gameplay 씬 즉시 동작 — 첫 실행 마찰 0 |

### 나쁜 것 / 위험

- **GameplayUI.cs 비대** (~280 lines) — Phase 18에서 GridRenderer / TrayRenderer / ResultHandler 등으로 분리 권장

- **씬 전환 시 EventBus / Controller 인스턴스 새로 만듦** — 진행 상태가 PlayerPrefs로 저장되지 않으면 손실. ProgressionService.Save가 이를 커버하지만 currentLevel 외 진행 중 보드 상태는 미보존
